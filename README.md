## 4. Quickstart

**Runtime:** Python 3.12 · **OS tested:** Ubuntu, Windows (CI)

With Docker:

```bash
docker compose up --build
```

Without Docker, using [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run python run_demo.py
```

Or with pip:

```bash
pip install -r requirements.txt
python run_demo.py
```
